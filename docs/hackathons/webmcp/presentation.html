Overview

What is AgentBadge?

AgentBadge is the first platform that exposes compliance scanning, on-chain identity, and verification tools directly to AI agents through the browser's native document.modelContext interface.

  • Compliance Scanner: 145+ checks across 18 categories — robots.txt, llms.txt, agents.txt, OpenAPI, WebMCP, SEO/AEO
  • On-Chain Passports: Issue and verify agent identity NFTs on Hedera and EVM chains
  • Compliance Badges: Generate SVG badges for visual compliance indicators
  • Rule Library: Searchable database of 145+ agent readiness rules

Discovery

WebMCP Discovery

Agents discover available tools automatically via the WebMCP discovery endpoint:

GET /.well-known/webmcp.json

The manifest lists all tools with endpoints, permissions, and descriptions. The browser mediates all calls — agents never need API keys.

Identity

On-Chain Agent Passports

Verifiable Agent Identity

Issue and verify on-chain NFT passports for AI agents on two chains:

  • Hedera: did:hcs:{tokenId}:{serial}
  • EVM (Base): did:eip155:{chainId}:passport:{address}:{tokenId}

Agents can verify each other's identity on-chain — no central authority required.
