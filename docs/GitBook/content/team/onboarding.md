# Team Onboarding

Welcome to the AgentBadge team! Here's how to get started.

## 1. Access Setup

- **GitHub:** Get invited to the repository
- **GitBook:** Get invited to the organization space
- **Hedera:** Create a testnet account at [portal.hedera.com](https://portal.hedera.com)

## 2. Local Development

Follow the [Installation Guide](../getting-started/installation.md) to set up your environment.

## 3. Understand the Architecture

Read the [Architecture Overview](../getting-started/architecture.md) to understand how the system works.

## 4. Pick a Task

- Check the [EPICs](../epics/README.md) for active work
- Each EPIC has slices — small, atomic tasks
- Pick a slice that matches your skills

## 5. Development Workflow

1. **Read** the slice document
2. **Write** failing tests (Red phase)
3. **Implement** minimal code to pass tests (Green phase)
4. **Refactor** and clean up
5. **Create** a pull request
6. **Review** and merge

## 6. Documentation

- **Code changes** — update relevant docs in `docs/GitBook/content/`
- **New features** — add a page and update `SUMMARY.md`
- **EPICs** — keep the EPIC summary pages up to date

## 7. Communication

- Use GitHub PRs for code review
- Use GitBook Change Requests for documentation review
- Reference EPIC slice IDs in commit messages
