# EPIC-78: MCP REST Parity Compliance

## Goal

Ensure MCP tools exposed via REST API have matching schemas, parameters, and response formats with their MCP counterparts.

## Key Deliverables

- REST API endpoints for all 65 MCP tools
- Schema validation matching MCP tool schemas
- Consistent error handling and response formats
- OpenAPI spec generation from MCP tool definitions
- Integration tests verifying MCP/REST parity
