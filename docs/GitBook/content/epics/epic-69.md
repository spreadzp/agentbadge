# EPIC-69: AgentGrade CLI Gap Closure

## Goal

Close the feature gap between AgentBadge CLI and the reference agentgrade-cli implementation, adding new fetchers, JSON output, and badge generation.

## Key Deliverables

- CLI feature parity with agentgrade-cli
- New fetchers for missing resource types
- JSON output format for machine-readable results
- Badge generation from CLI
- Test coverage for all CLI commands
