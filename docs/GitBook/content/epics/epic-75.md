# EPIC-75: AgentGrade Rule Expansion

## Goal

Expand the scanner ruleset from 97 to 104 rules, adding new categories for SEO/AEO and accessibility compliance.

## Key Deliverables

- Ruleset expanded from 97 to 104 rules
- New category: **seo_aeo** (9 rules) — SEO/AEO metadata, OG tags, structured data
- New category: **accessibility** (2 rules) — WCAG compliance checks
- Rule definitions AB-100 through AB-118
- Updated scoring engine for new categories
- Test coverage for all new rules
