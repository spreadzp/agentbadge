# EPIC-67: Stripe Payment Integration

## Goal

Add Stripe as an additional payment rail alongside x402 (HBAR), MPP, and L402 (Lightning) for passport issuance and marketplace transactions.

## Key Deliverables

- Stripe checkout integration for passport purchases
- Webhook handling for payment confirmation
- Unified payment interface across all rails (x402, MPP, L402, Stripe)
- Environment-based payment rail selection
