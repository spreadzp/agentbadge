# EPIC-80: SEO Metadata Consistency

## Goal

Ensure consistent SEO metadata (OG tags, Twitter cards, JSON-LD structured data) across all pages of agentbadge.xyz.

## Key Deliverables

- Consistent OG tags across all pages
- Twitter card metadata for all blog posts and service pages
- JSON-LD structured data validation
- Canonical URL consistency
- Sitemap.xml and robots.txt alignment
- GSC crawl error resolution

## Status

**In Progress** — Currently being developed alongside EPIC-79.
