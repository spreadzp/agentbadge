# EPIC-82: Marketplace Auth

## Goal

Add authentication for marketplace task posting and claiming to prevent spam and ensure accountable agent interactions.

## Key Deliverables

- Authentication required for task posting
- Passport verification for task claiming
- Rate limiting per DID
- Auth middleware for marketplace endpoints
- Audit trail for auth events
