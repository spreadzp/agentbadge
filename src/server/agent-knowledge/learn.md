# Learning Path

## How to Make Your API Agent Ready

1. **Understand what Agent Readiness is** — Read [/agent-guide/context](/agent-guide/context)
2. **Check your API** — Run a scan using the web UI or CLI
3. **Read your report** — Understand your score and findings
4. **Fix issues** — Follow recommendations for each capability
5. **Display your badge** — Show your Agent Readiness score
6. **Keep improving** — Re-scan after changes, track progress over time
